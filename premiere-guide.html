Open a completed job's Render page

Go to Jobs, click a DONE job, then scroll to the Premiere Pro section.

2

Click "Connect inside Premiere"

This registers a pending bridge session on the backend. The panel will pick it up on its next poll (within 3 seconds).

3

Panel shows the job — click Apply

The AI Render Bridge panel inside Premiere detects the pending job automatically and shows a one-click Apply button.

Outdated project link? Click Reconnect and refresh link first — it re-exports the .prproj before creating a bridge session. The "Connect inside Premiere" button is grayed out when the link is stale.

Manual fallback: Expand "Enter pairing code manually" at the bottom of the panel. Copy the code from the web UI and paste it there.
