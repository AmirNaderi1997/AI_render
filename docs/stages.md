# AI Render — Stages

هر مرحله یک خروجی قابل استفاده دارد. تا مرحله‌ای کامل و تست نشده، سراغ بعدی نمی‌رویم.
مهارت‌های هر مرحله در [skills.md](skills.md) و معماری در [plan.md](plan.md) است.

---

## مرحله ۰ — آماده‌سازی

**کارها**
- نصب روی سیستم تدوین (مک): `brew install ffmpeg mlt`، نصب Kdenlive از kdenlive.org، `pip install faster-whisper`، Python 3.11+ و Node 20+
- ساخت پوشه‌ی `rafiei-ai-editor/` با ساختار `raw/ music/ sfx/ broll/ presets/ exports/ references/`
- جمع کردن ۱۰ تا ۲۰ ریل قبلی که ادیتشان را دوست داری در `references/`
- چند موزیک، whoosh/pop و B-roll اولیه در کتابخانه
- نصب فونت کپشن (مثلاً Vazirmatn برای فارسی، Montserrat برای انگلیسی)

**تمام است وقتی:** `melt --version`، `ffmpeg -version` و `python -c "import faster_whisper"` کار می‌کنند و Kdenlive باز می‌شود.

## مرحله ۱ — JSON Edit Plan → MLT/Kdenlive → MP4 (+ UI پایه)

**هدف:** یک plan دستی بدهی و ریل رندرشده بگیری. هنوز هیچ AI در کار نیست.

**کارها**
- Schema برای Edit Plan (Pydantic) — مهارت A1
- `build_mlt.py`: cut، zoom، کپشن ASS، B-roll، موزیک با ducking، SFX — مهارت‌های A2 تا A8
- `render.py`: رندر نهایی و پیش‌نمایش کم‌کیفیت با `melt` — A9
- خروجی قابل باز شدن در Kdenlive — A10
- CLI: `python -m engine render plan.json`
- **UI پایه:**
  - صفحه‌ی **New Reel**: آپلود ویدیوی خام + آپلود/پیست `plan.json`
  - صفحه‌ی **Plan Review** نسخه‌ی ساده: ویرایشگر JSON با اعتبارسنجی و تایم‌لاین نمایشی فقط‌خواندنی
  - صفحه‌ی **Render**: دکمه‌ی Render، نوار پیشرفت، پخش MP4، دانلود، دکمه‌ی Open in Kdenlive
- تست‌ها: هر ویژگی یک plan نمونه و بررسی خودکار خروجی با `ffprobe` (مدت، رزولوشن، وجود صدا)

**نقطه‌ی شروع:** کد تست‌شده در [`proof/`](proof/README.md) (`build_mlt.py` و `plan.json`) که همین مسیر را برای همه‌ی ۷ ویژگی نشان داده است.

**تمام است وقتی**
- یک ویدیوی واقعی خودت با یک plan دستی به ریل 1080x1920 با هر ۷ ویژگی تبدیل شود
- همان پروژه در Kdenlive باز شود
- کل کار از UI و بدون ترمینال انجام شود

## مرحله ۲ — AI Brain: ویدیوی خام → JSON Edit Plan

**هدف:** فقط ویدیو را بدهی و بگویی «با Rafiei Reel Style ادیت کن».

**کارها**
- ترنسکریپت کلمه‌به‌کلمه با Whisper — B1
- تشخیص مکث — B2، حذف تکرار و اشتباه — B3
- Planner با LLM و پروفایل استایل اولیه (دستی نوشته‌شده) — B4، B5
- **UI:**
  - در **New Reel**: انتخاب استایل + یک خط دستور آزاد + دکمه‌ی Generate Edit Plan
  - در **Plan Review**: ترنسکریپت کلیک‌پذیر، تایم‌لاین قابل ویرایش (متن کپشن، زوم، حذف/برگرداندن بخش)، پیش‌نمایش سریع

**تمام است وقتی:** روی ۵ ویدیوی خام، plan تولیدشده بدون خطای schema رندر شود و کمتر از ۵ اصلاح دستی لازم داشته باشد.

## مرحله ۳ — Auto Assets: B-roll + Music + SFX

**هدف:** AI خودش از کتابخانه B-roll، موزیک و SFX مناسب انتخاب کند.

**کارها**
- ایندکس تگ‌دار کتابخانه — C1
- انتخاب B-roll با تگ یا embedding — C2
- انتخاب موزیک و SFX — C3
- **UI:** صفحه‌ی **Library** (آپلود، تگ‌گذاری، پیش‌نمایش)؛ در Plan Review، برای هر B-roll سه گزینه‌ی جایگزین

**تمام است وقتی:** در ۸ از ۱۰ ویدیو، B-rollها از نظر تو مرتبط باشند.

---

## مرحله ۴ — Auto QC: رندر → بازبینی AI → اصلاح → رندر دوباره

**هدف:** سیستم خودش خروجی را ببیند، ایرادها را پیدا کند و نسخه‌ی بهتر بدهد.

**کارها**
- نمونه‌برداری فریم و صدا — D1
- بازبینی با LLM بینایی — D2، بررسی‌های قطعی (صورت، لودنس، تصویر ثابت) — D3
- patch روی plan و رندر v2 — D4 (حداکثر ۲ دور خودکار)
- **UI:** صفحه‌ی **Render & QC** با لیست ایرادها روی تایم‌لاین، Apply fix برای هر مورد، Fix all & re-render، مقایسه‌ی v1 و v2

**تمام است وقتی:** ایرادهای معمول (کپشن روی صورت، موزیک بلند، تصویر ثابت طولانی) در نسخه‌ی دوم خودکار رفع شوند.

## مرحله ۵ — Rafiei Style: یادگیری از ریل‌های قبلی

**هدف:** خروجی شبیه ادیت‌های خودت شود، نه یک استایل عمومی.

**کارها**
- تحلیل ریل‌های مرجع — E1
- ساخت پروفایل `rafiei_reel.yaml` و نمونه‌های few-shot — E2
- یادگیری از اصلاحات تو در UI — E3
- **UI:** صفحه‌ی **Style** برای دیدن و ویرایش پروفایل و آپلود ریل مرجع جدید

**تمام است وقتی:** در مقایسه‌ی کور، نیمی از ریل‌های AI را از ادیت دستی خودت تشخیص ندهی.
