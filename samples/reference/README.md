# Kdenlive project references

These are unmodified Kdenlive-saved project files from KDE's official
[kdenlive-test-suite](https://invent.kde.org/multimedia/kdenlive-test-suite).
Both declare `kdenlive:docproperties.kdenliveversion` 24.11.70 and document
format `1.1`; their XML was saved by Kdenlive, not constructed for this repo.

- [`audio-mix.kdenlive`](https://invent.kde.org/multimedia/kdenlive-test-suite/-/raw/master/projects/audio-mix.kdenlive): audio playlists, per-track tractors, mix transitions, bin metadata.
- [`transform.kdenlive`](https://invent.kde.org/multimedia/kdenlive-test-suite/-/raw/master/projects/transform.kdenlive): video playlists, per-entry transform filter, sequence and project tractors.

Fetched 2026-09-30 from the repository's `master` branch. The reference media
paths point into the upstream test suite; they are retained here for format
inspection, not local rendering.
